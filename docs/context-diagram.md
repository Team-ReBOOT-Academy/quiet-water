# Контекстная схема

Рядом с [проектным документом](project-description.md).
На схеме только внешние участники и направление обмена. Классы внутри процесса сюда не входят.

Пользователя личного кабинета у `quiet-water` нет: портфель смотрит преподаватель на платформе, сервис запускает студент.
Транспорт платформы на схеме не назван: сервис видит платформу, а не отдельный брокер.
Поставщик рыночных данных сюда не входит: к сервису он не подключён.

```mermaid
flowchart LR
  student["Студент llnightll"]
  teacher[Преподаватель]
  platform[Teacher Trading Platform]
  service[quiet-water]
  probe["curl / браузер"]

  teacher -->|"выдаёт доступ к платформе"| student
  student -->|"запуск, переменные окружения, остановка"| service
  service -->|"account.registration.request и strategy.recommendation.created"| platform
  platform -->|"показывает портфель и результат прогона"| teacher
  probe -->|"GET /health без авторизации"| service
```

| Откуда | Куда | Зачем |
|---|---|---|
| Преподаватель | Студент | Один раз выдаёт доступ к платформе. В Git эти значения не попадают |
| Студент | quiet-water | Поднимает процесс и останавливает его |
| quiet-water | Платформа | При старте просит регистрацию, затем публикует одно решение на свечу |
| Платформа | Преподаватель | Показывает портфель. Это не UI нашего сервиса |
| curl / браузер | quiet-water | Проверка живости. Авторизации нет |
