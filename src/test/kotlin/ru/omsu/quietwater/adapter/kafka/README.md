# Тесты Kafka

Брокер не нужен: отправка записывается в память.

- `KafkaClientPropertiesTest.kt` — свойства SASL-клиента и отсутствие учётных данных при PLAINTEXT.
- `RegistrationFlowTest.kt` — заявка на регистрацию, публикация отложенной свечи после принятия, игнор чужого аккаунта и отказ.
- `CandleToRecommendationTest.kt` — пример свечи становится одним событием рекомендации HOLD, а неполный payload отклоняется до публикации.
