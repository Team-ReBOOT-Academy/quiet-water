# Закрытая свеча

- `ClosedCandleCommand.kt` — команда «закрылась свеча»: исходное событие, correlation id и сама свеча.
- `BaselineHold.kt` — фиксированная базовая рекомендация, которую сервис отдаёт, пока торговый сигнал не публикуется.
- `ProcessClosedCandle.kt` — кладёт свечу в окно инструмента, собирает рекомендацию из базового HOLD и отдаёт её издателю.
