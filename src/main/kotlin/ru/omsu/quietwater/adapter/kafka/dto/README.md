# Тела сообщений

- `EventEnvelopeDto.kt` — конверт: идентификаторы, тип, версия схемы, время, producer и произвольный payload.
- `CandlePayloadDto.kt` — тело свечи: инструмент, прогон, номер и цены.
- `RegistrationRequestPayload.kt` — заявка на регистрацию счёта: имя, группа, секрет и идентификаторы студента и стратегии.
- `RegistrationResultPayload.kt` — ответ платформы: принятый счёт и сессия либо причина отказа.
- `RecommendationPayloadDto.kt` — исходящая рекомендация со счётом, сигналом и ссылкой на исходную свечу.
