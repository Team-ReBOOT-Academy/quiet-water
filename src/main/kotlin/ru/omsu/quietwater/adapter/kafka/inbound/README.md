# Входящий поток

- `KafkaCandleListener.kt` — в отдельном потоке читает топики, переподключается с нарастающей паузой и коммитит offset после обработки.
- `IncomingEventHandler.kt` — разбирает событие: регистрацию принимает или отклоняет, свечу проверяет и либо обрабатывает сразу, либо держит до принятия регистрации.
