# Ресурсы

Файлы попадают в classpath собранного сервиса.

- `application.conf` — значения по умолчанию: HTTP, Kafka, типы событий, базовая рекомендация HOLD и пороги стратегии. Переменные окружения их перекрывают.
- `logback.xml` — лог в консоль на уровне INFO; Netty и клиент Kafka приглушены до WARN.
